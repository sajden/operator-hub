## Planned Tagging

När vi väljer standardmusik för short-form ska varje spår få:
- `mood`
- `energy`
- `tempo`
- `best use`
- `avoid when`

Exempel:
- `mood: calm / tense / playful / adventurous`
- `energy: low / medium / high`
- `best use: intro / news explainer / CTA / outro / background bed`
